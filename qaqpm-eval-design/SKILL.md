# QAQPM-评测与测试集（S7）

笔记锚点：day17 评测六步与四时点；w4d2；架构 §5（设计早、执行晚）；飞书美团评测节／国华 3.8 defer。

## 1. 何时用 / 何时不用
**用**：S6 通过或条件通过后，写 PRD 前准备测试集与门禁。  
**不用**：开发后对照跑分 → S11；只选型对比且无门禁设计 → 可与 S9 交错，但黄金集草案仍归本站。

## 2. 上游依赖
S6 档位与质量门槛；S5 核心假设；S1 AI 适用性。启用飞书时读 `_shared/feishu-doc-protocol.md`。

## 3. 目标与通过线
完成六步中的设计侧：①目标 ②标准 ③评测集结构（及黄金集 v0）④打分方式约定 ⑤报告模板骨架 ⑥归因框架。  
覆盖：维度菜单、GSB／裁判校准、RAG 检索+回答+蒙对、Agent 过程+结果、报告四行。  
**不**在本站伪造已跑分数。PRD 验收必须能引用本站门禁。

### 存储形态（硬规则）

| 模式 | 权威载体 | 本地必有 |
|---|---|---|
| 本地-only | `eval/` 索引 + 单题文件 | `07-评测设计与测试集.md` + `eval/` |
| **飞书存储** | **飞书多维表格（评测集/黄金集）** | `07` 文档 + `eval/` **全字段只读镜像**（行数 ≥ 表内有效记录） |

- 用户采用飞书存文档时：**必须**用多维表格存评测集，禁止只用普通飞书文档里的 Markdown 表充当题库。
- 多维表至少三个视图：全部题目、红线题、本轮门禁冻结集。
- 字段至少：题号、题型、场景标签、输入摘要、预期要点、适用维度、来源、状态、门禁版本、备注；（RAG/Agent 追加专用列）。
- `07` 写清多维表 URL、镜像路径、「设计≠已跑分」。
- 无本地镜像或行数对不齐 → **S7 自检不通过**（不得宣称黄金集 v0 就绪）。

## 4. 引导流程
| Phase | 产出 |
|---|---|
| P0 | 评测支持的决定；标明四时点；判定 storage_mode=local\|feishu |
| P1 | 从维度菜单选 3–5 维并排序（效果/安全/体验/成本） |
| P2 | 形容词→可观察条件；分档+样例；人人一致性计划 |
| P3 | 题型：正常/边界/红线/反例；题源：真实>专家>AI补 |
| P4 | 落盘 `eval/`；**飞书模式**：创建/更新评测集多维表与视图 → 写本地镜像 → 回读对账；RAG/Agent 附加字段若需要 |
| P5 | 打分约定（是非／1-5／GSB）+ AI 裁判校准计划 |
| P6 | 门禁草案；报告四行骨架；归因框架 |
| P7 | 写 `07` + 官方三件套骨架；交接 → S8 |
