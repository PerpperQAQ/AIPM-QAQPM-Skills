# 竞品唱反调 · 固定 Prompt

> 来源：day13 反方论证纪律。产出必须进 `04-竞品分析.md`「反方论证」节。

```text
你现在是唱反调的评审，不是帮助我们圆故事的顾问。
已知：我们的目标用户、场景、差异化一句话、竞品名单与同维事实表（如下）。
请只基于已给事实与合理推断，回答：
1. 对手最可能用什么组合打败我们？
2. 我们的差异化里哪一句最经不起核查？需要什么证据才站得住？
3. 若用户继续用「现有凑合办法」，我们凭什么让他迁移？
4. 列出 3 条「若成立则应不立项／缩小范围」的条件。
禁止：编造未提供的用户量、融资额、模型能力排名；不确定处标【待确认】。
```

把模型输出中的断言改写回表格，每条打上【推断】／【待确认】，人工决定是否采纳。
