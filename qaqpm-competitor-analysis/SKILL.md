# QAQPM-竞品分析（S4）

笔记锚点：day13「04 看清对手」五步；day11 五层；OiiOii 市场三层；框架阶段④。

## 1. 何时用 / 何时不用
**用**：回答别人做了吗、凭什么是我们。  
**不用**：纯自我拆解练习且无竞争决策 → 用 S6 拆解模块即可。

## 2. 上游依赖
S1/S2/S3；拆解模板见 `../qaqpm-go-nogo/references/`。

## 3. 目标与通过线
- **四种目的**先选一：0→1 找空位／1→N 找增量／对手出招跟不跟／潜在进入者威胁。  
- 差异化公式：盯 X 用户，最在乎 Y，竞品做不了因 Z（Z 有依据）。  
- **必须有反方论证**（可用固定唱反调 prompt）。  
- AI 产品看完整输出物，不只看有没有按钮。

## 4. 引导流程
P0 **定目的（四选一）** → P1 四类竞品 → P2 统一维度（**含市场层**：蛋糕／阶段／谁在抢；工具／平台／模型三层）→ P3 同任务收信息 → P4 结论+唱反调 → P5 可选五层深拆。

### 收信息四处纪律
1. 自己当用户完成同一任务（截图／输出物）。  
2. 官网／定价／文档／更新日志（标日期）。  
3. 用户公开反馈（转成可复现任务，差评≠已验证需求）。  
4. 招聘／融资／专利仅作线索，标【推断】或【待确认】。
