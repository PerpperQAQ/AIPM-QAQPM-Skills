# 访谈逐字稿记录纪律（5 条）

> 框架来自轻颜「访谈记录说明」页（结构）。用于 `research/interviews/`。

1. **双源交叉**：优先「妙记／录音转写 + 第二路识别」交叉整理；注明是否已全程审听。  
2. **（？）标听不准**：橙色或括号候选说法，不装听清。  
3. **主题标签 + Q 编号·时间码**：提问格首行便于回放与对齐需求（如 Q001 · 00:00:06）。  
4. **原话不美化**：保留停顿、否定、程度词；只拆条转写，不改成产品话术。  
5. **【表格】行非原话**：画像整理、替他人附和、装了哪些 App 等反贴整理须标记；与需求弱相关可单列，删口头语须说明规则。

禁止：把整理段当成用户原话引用进立项。
