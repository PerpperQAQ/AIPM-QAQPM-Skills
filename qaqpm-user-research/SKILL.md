# QAQPM-用户研究（S2）

笔记锚点：day12「02 找到真用户」；立项验证工具包 A/B；轻颜问卷／访谈说明；架构 §4。

## 1. 何时用 / 何时不用
**用**：验证谁真有问题、有多疼；立项前补证据。  
**不用**：已有高强度证据且只排序需求 → S3；只做竞品体验 → 可与 S4/G 联动。

## 2. 上游依赖
S1 问题卡（可双入口后补）；`_shared/research-methods.md`；已有 `research/`。

## 3. 目标与通过线
- 至少若干人能讲出**具体事件**（非抽象吐槽）。  
- 补救成本达到「值得解决」阈值（项目自定义）。  
- 正式立项：≥1 高强方法，或 2 中强且标明局限。  
- 反例：只有「感觉很多人需要」且无原话 → 全部【待确认】，不进立项依据。

## 4. 引导流程
| Phase | 内容 | 跳过 |
|---|---|---|
| P0 | 本轮要验证的 1–3 个假设 | 已有 |
| P1 | 分群：生命周期／消费／动机 | |
| P2 | **选用户四类**各准备问法（见下） | |
| P3 | 画像四维：知道什么／在乎什么／何时用／因何卡住 | |
| P4 | 勾选方法 A–H | |
| P5 | 执行：模板写入 `research/` | |
| P6 | 判读 + `02` + 交接；可选「用户-场景-需求」表再进 S3 | |

研究五步：定目标 → 选用户 → 设计问题 → 执行 → 整理输出。  
**定量 what + 定性 why**：问卷／日志回答「多少人、多频」；访谈／走查回答「为何、如何凑合」。二者成对写进发现，禁止只用比例代替原因。

Mom Test：问生活与做过的事，不让人评价你的想法。

### 选用户四类 · 示例问句

| 类型 | 想验证什么 | 示例问句 |
|---|---|---|
| 重度 | 高频场景与不可替代点 | 最近一周哪几次必须用？若少了哪一步会改用别的办法？ |
| 边缘 | 偶发触发与放弃点 | 上次差点用却没用，卡在哪？什么条件会再试？ |
| 流失 | 离开原因与竞品切换 | 是从什么时候少用的？后来改用什么？哪一步最失望？ |
| 潜在 | 是否真有问题、现有凑合 | 最近一次遇到【问题】怎么处理的？花了多久？有没有找人帮忙？ |

## 6. 输出大纲（02-用户研究.md）

## 7. 证据规则
原话／行为数字=【事实】；归纳痛点=【推断】挂原话编号；未访人群=【待确认】。
