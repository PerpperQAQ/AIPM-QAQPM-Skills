# 模型初筛表 Schema（引用课程 Base，不搬价目全文）

> **框架来自**飞书「模型总览 List」多维表（提取件 `01-模型总览List.md`）。  
> **纪律**：Skill 内只保留**字段与视图约定** + **2–3 行脱敏示意**；禁止把 235 行价目当秘密再发布。单价以课程 Base／官网溯源为准，用时现查。  
> 货币常见 **$ / ¥ 混用**，比较前必须统一口径或分列，并标【待确认】若未换算。

## 1. 视图约定

| 视图 | 含义 |
|---|---|
| 总表 | 平铺全类型 |
| LLM | 类型 = LLM |
| Video | 类型 = 视频模型 |
| Image | 类型 = 图片模型 |

页脚 records 数为 Base 规模提示（提取时总表约 235）；以你当前 Base 为准。

## 2. 初筛必填列（对齐 List）

| 列名 | 说明 |
|---|---|
| 模型版本名称 | 厂商／系列名（父级，如 Claude、Doubao） |
| 类型 | LLM／视频模型／图片模型 |
| 具体版本名 | API 可调用的版本串 |
| 模式 | 如闭源可接 API／开源自托管等 |
| 计费维度 | token／Package／image／video |
| 计费单位数量 | 如 1M token、1 image、1S |
| api 输入价格 | 按计费维度填写；无则「-」 |
| api 输出价格 | 同上 |
| 溯源地址 | 官网／价目页 URL（必填，便于复核） |
| 父记录 | 挂到同一厂商系列 |
| 详细价格补充 | 档位、分辨率、是否含音频等短注 |

可选：父记录 3（Base 有列名；含义以表内为准，不编造）。

## 4. 如何在项目里引用

1. 打开课程 Base（或自建同 schema 表）。  
2. 按任务类型筛选 LLM／Image／Video。  
3. 复制**候选行**到本项目 `09-POC与选型.md` 初筛表（含溯源 URL）。  
4. 精筛阶段用 S7 冻结子集跑分，成本列用「单位价格 × 预估用量」公式，禁止无来源填死数字。

## 5. 与选型四步的关系

初筛用本 schema 收窄 → 精筛对齐业务维表 → 对比（含 GSB）→ 定主／辅模型。详见 S9 `SKILL.md`。
