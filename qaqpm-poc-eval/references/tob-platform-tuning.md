## 3. PM 三步（选型实验）

1. **定范围**：场景、资料类型、必须通过的题型。  
2. **出题打分**：用 S7 黄金集子集；一次改一个主变量。  
3. **出报告**：结论四行；主／辅模型与平台建议。

## 4. 调优实验入口（高水平，不贴长提示词）

| 旋钮 | 试什么 | 记录 |
|---|---|---|
| 切分 | 章节／递归／固定大小／语义／表格（五种方向） | 失败片段截图+题号 |
| Top-K／Top-N | 过小断章、过大吵且贵 | 召回 vs 准确率曲线 |
| 混合检索权重 | 关键词 vs 语义（和为 1） | 场景：故障码偏关键词等 |
| 重排阈值／兜底 | 最高分仍低 → 拒答／转人工，不硬编 | |
| 路由 | 多库时是否进对库 | |

平台 vs 框架：先比现成平台（Dify／FastGPT／RAGFlow／云厂商等）在本业务的缺口；只有真实样本暴露关键缺口且定制收益覆盖维护，再自研框架。
