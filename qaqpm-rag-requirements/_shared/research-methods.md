# QAQPM 调研方式菜单 A–H

> 来源：架构 §4；day12 用户研究五步 / Mom Test / 定量定性；立项验证工具包 A/B。  
> S2 按项目勾选；正式立项至少 **一种高强度**，或 **两种中强度且标明局限**；纯 H/E 最多支撑**条件立项**。

| 代号 | 方式 | 强度 | 适用 | 主模板（S2/templates） |
|---|---|---|---|---|
| A | 深度访谈 | 高 | 可触达目标用户 | `A-深度访谈.md` |
| B | 同任务走查 / 对照实验 | 高 | 有替代方案可对比 | `B-同任务走查.md` |
| C | 行为 / 日志分析 | 高 | 已有可观测数据 | `C-行为日志分析.md` |
| D | 社交原声采集 | 中 | 方向探索、二手信号 | `D-社交原声采集.md` |
| E | 问卷 | 中低 | 验证频次 / 分布 | `E-问卷.md` |
| F | 专家 / 老师访谈 | 中 | 校正术语与可行性 | `F-专家访谈.md` |
| G | 竞品体验走查 | 中 | 与 S4 联动 | `G-竞品体验走查.md` |
| H | 桌面研究 | 中低 | 市场 / 行业结构（不作唯一依据） | `H-桌面研究.md` |

## 选用决策树（一次一问）

1. 能不能约到真人目标用户？→ 能：优先 A；不能：看 2。
2. 有没有现成产品日志 / 漏斗？→ 有：C；没有：看 3。
3. 有没有可对比的现有凑合方案？→ 有：B；没有：看 4。
4. 只需校正术语 / 可行性？→ F。
5. 方向还很糊、先找信号？→ D + H，并标明「不作立项唯一依据」。
6. 需要分布数字？→ E 作为补充，不单独支撑「痛点真实」。

## 立项证据门槛（写入 S2 / S6）

| 拟结论档 | 最低证据 |
|---|---|
| 立项（go） | ≥1 高强，或 2 中强且局限写清；有带编号原话或行为数字 |
| 条件立项 | 允许 1 中强 + 验证日历；纯 E/H 必须写清第几周补 A/B/C |
| 不立项 / 暂缓 | 证据不足或假设被推翻亦可——把原因写进报告 |
