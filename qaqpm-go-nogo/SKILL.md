# QAQPM-立项决策（S6）

笔记锚点：day13「06 拍板立项」；day11 五层五问；框架阶段⑥。  
**升级合并**：原 `ai-product-teardown` 全文进入 `references/`，取消独立旁路 Skill。

## 1. 何时用 / 何时不用
**用**：值不值得投入；条件与止损；或「拆解某 AI 产品」喂决策/竞品。  
**不用**：问题与证据未齐（总控应拦）；已立项只写图纸 → S7/S8。

## 2. 上游依赖
S1 问题卡 + S2 证据强度 + S5 MVP（含**架构取舍表**）+ S4 差异化；可选 S9 草案。  
长讨论对照 `research/已确认决策表.md`。  
拆解时读 `references/`：`teardown-module.md`（入口）、`templates.md`、`toolkit.md`、`experience-guide.md`、`report-guide.md`、`report-template.html`、`fill_report.py`、`example-oiioii.md`。

## 3. 目标与通过线
- 共同三问：用户价值？业务价值？可行性？（day13）  
- AI 四问：适用性？质量门槛？错误兜底？数据与调用成本？  
- 结论档位三选一（或暂缓）：**立项 / 条件立项 / 不立项**（+ 暂缓）  
- 条件立项必须：第几周验什么、什么数据转正、什么情况止损（可写**相对验证周期**，但必须绑定 G 门禁题号，禁止空日历）  
- 决策摘要必须**引用 S5 架构取舍表**（执行位置／访问入口等）  
- 拆解：五层链完整、每条结论有证据标签；可附架构图

### 作品 / 面试 / 教学双目标（若用户目标含此类）
06 必须单开「证据链」节：**问题 → 取舍 → 可运行 → 试用结果 → 迭代**；与纯 ToB 商业指标分行，禁止用商业 KPI 冒充作品完成度。

## 4. 引导流程

### 路径 A：立项决策（默认）
| Phase | 内容 |
|---|---|
| P0 | 确认上游齐：问题卡、证据强度、MVP+架构取舍、差异化 |
| P1 | 三问打分或质性判断（分数须附依据，防总分掩盖缺口） |
| P2 | AI 四问逐项 |
| P3 | （推荐）对本方案或关键竞品跑拆解模块，结论进附录 |
| P4 | 写立项报告八部分（day13）+ 架构取舍引用 +（若适用）面试证据链 |
| P5 | 明确档位 + 止损/验证日历（绑门禁题号） |
| P6 | 交接区；默认下一站 **S7** |

### 路径 B：只拆解
| Phase | 内容 |
|---|---|
| P0 | 产品、目的、深度（练习/竞品/0→1/1→N/效果迭代） |
| P1–P5 | 按 `references/teardown-module.md` Step 0–5 |
| P6 | 若服务立项：摘要写入 `06` 附录；若服务竞品：回 S4 |

### 跳过条件
- 成熟型用户已有完整证据包：可压缩 P1 问答，但仍须写档位与止损。  
- 非 AI 项目：AI 四问改写为「自动化/规则」适用性，可简。

## 5. 方法与模板库
- 立项正文模板：`templates/06-立项报告.md`、`templates/决策矩阵.md`  
- 拆解：`references/teardown-module.md` + 原 teardown 配套文件  
- 收益测算纪律：标「测算/未复核」；相关≠因果（day13）  
- 工期：AI 估算必须标【待确认】并交执行团队确认

## 6. 输出文档大纲（06-立项报告.md）

| 部分 | 必/选 | 要点 |
|---|---|---|
| 00 决策摘要 | 必 | 做不做、投入、何时检查/停止；引用架构取舍 |
| 01 背景与问题 | 必 | 链 S1 |
| 02 用户与场景 | 必 | 链 S2 证据 |
| 03 市场与竞品 | 必 | 链 S4 + 可选拆解 |
| 04 目标与成功指标 | 必 | 基线/目标/口径；作品目标分行 |
| 05 方案与第一版范围 | 必 | 链 S5 |
| 06 投入与计划 | 必 | 人钱时间依赖 |
| 07 风险与停止条件 | 必 | 止损可执行（含入口撤权/预览串任务等若适用） |
| 08 面试/作品证据链 | 条件必 | 目标含作品/面试时 |
| 附录 A 五层五问拆解 | 强推荐 | 或外链拆解文件 |
| 交接区 | 必 | decision_tier 等 |

## 7. 证据规则
全站 labels；拆解沿用 teardown 纪律（完成回页面、官方回原文）。业务方收益数字标性质。官方能力记载 ≠ 本项目已验证。
