# 输出模板

> 用法：§1 是拆解文档的整体骨架，§2 是各层可直接复制的表格。按 Step 0 定好的深度删减，不需要的层或小节直接删掉，不要硬填。
> 每个单元格或每条结论都标【事实】【推断】【待确认】中的一个。

- 测试场景：<一句话 + 输入原文>；测试轮次：模糊 / 具体 / 异常
