# 双轨模块对照 + PRD↔课件八块

## 1. 课件八块 ↔ `08-PRD/` 文件

| # | 课件八块 | 落到文件 | 要点 |
|---|---|---|---|
| ① | 文档信息 | `00-文档信息.md` | 版本、作者、评审 |
| ② | 概述／假设 | `01-背景与目标.md` + 决策包 | 问题、目标、关键假设 |
| ③ | 范围 | `03-范围-含不做.md` | must／wont；链 S5 |
| ④ | **角色和权限** | `05b-角色和权限.md`（新增；与 `05-业务规则.md` 并列） | 能用／能看／不能做；可选项目组职责表 |
| ⑤ | 场景流程（正常／异常／转人） | `06-流程与状态.md` | 可填表，非空标题 |
| ⑥ | 功能五件事 | `04-功能说明.md` | 前提／操作／规则／兜底／验收 |
| ⑦ | **AI 三问** | `08-AI能力与评测验收.md` | 做什么／多好／谁兜底；低置信度转人；闭环 |
| ⑧ | 指标与非功能 | `07-非功能.md` + `08` 门禁 + `10` 风险 | 可分层：检索／生成／业务 |

其余：`02-用户与场景.md`、`05-业务规则.md`、`09-里程碑.md`、`10-风险与开放问题.md` 支撑八块落地。

## 2. 正式 PRD ↔ Agent 规范

| 正式 PRD | Agent 规范 | 共享来源 |
|---|---|---|
| 背景与目标 | 概述与边界 | 决策包 |
| 用户与场景 | 用户流程 | S2 |
| 范围 | 概述不做清单 | S5 |
| 角色和权限 | 状态与异常（权限相关枝） | 本站 |
| 功能／规则／流程 | 状态与异常 + 接口 | 业务规则优先 |
| AI 与评测 | AI 行为 + 验收用例 | **S7** |
| 非功能／指标 | 技术栈／Tokens | S9 可回写 |
| 知识库／RAG 数据 | 数据模型 + AI 行为 | `meituan-prd-patterns`／KB 模板 |

## 3. Agent 光谱

人机分工与确认点设计交叉 **S6 拆解模块**、S9 技术链路；PRD 只写清「谁确认、何时转人」。
