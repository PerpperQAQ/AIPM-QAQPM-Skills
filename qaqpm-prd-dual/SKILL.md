# QAQPM-双轨PRD（S8）

笔记锚点：day13 PRD 八块与功能五件事；day16 三主线与美团案例；vibe-prd 10 模块；架构 §6。

## 1. 何时用 / 何时不用
**用**：立项后需要可协作图纸与可编码规范。  
**不用**：尚未有 S7 黄金集草案（可少量交错写结构，但验收章不得空写「效果要好」）。

## 2. 上游依赖
S5/S6/S7 交接；S4 差异化；可选 S9 选型结论。共享决策包可引用 `research/已确认决策表.md`。

## 3. 目标与通过线
- 同源决策包**先填满再冻结**，再分两套目录。  
- 课件八块映射齐全（含**角色权限、异常转人、AI 三问**）。  
- 测试能依据正式 PRD 写用例；Agent 规范可执行。

### 共享决策包硬门禁（P0）
下列任缺 → **禁止**将正式 PRD 标为终稿完成；允许「PRD 草案」，且 `00` 索引必须红字「决策包未冻」：
- 一句话目标、问题卡引用  
- MVP must / wont（含不做理由）  
- 差异化一句  
- S7 门禁引用（或明确「门禁草案路径」）  
- 非目标、里程碑、开放问题  
- 架构取舍摘要（执行位置／访问入口，引用 S5 表）  

空壳复制 PRD 目录表 ≠ 已冻。条件立项＋技术验证中项目可用「未冻 + 验证日历」样例，但不得假装已冻。

合订 MD 可交付，但 handoff 的 `prd_dir` / `agent_spec_dir` 必须与真实路径一致；合订时改用 `prd_path` / `agent_spec_path`。

## 4. 引导流程
P0 **填满并尝试冻结**共享决策包 → P1 选读者侧重 → P2 写正式 PRD（八块）→ P3 写 Agent 模块（+知识库若需要）→ P4 交叉检查范围与 S7 门禁 → P5 交接（frozen true/false 诚实填写）。
