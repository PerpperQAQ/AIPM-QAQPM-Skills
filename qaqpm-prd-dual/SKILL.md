# QAQPM · 需求细化与开发交接（S8）

> **本轮增量 Changelog 2026-10-29**：共享决策包展示名改为立项决策一页纸；必含已决｜仍要证明；附条件立项填好样例；frozen=false 红字。

笔记锚点：day13 PRD 八块与功能五件事；day16 三主线与美团案例；vibe-prd 10 模块；架构 §6。

## 1. 何时用 / 何时不用
**用**：完善可协作PRD与开发约定，或单独编写总体设计、功能需求及配套材料。S5已启动的专题继续原文件。完整开发交接需要适用S7标准与题集依据；首稿／单项请求可以先写已有依据，缺口标待确认。
**不用**：把产品Agent需求误当编码Agent规范；把未验证候选写成已验证技术选择。

## 单文档与专题模式

先读[_shared/ai-document-protocol.md](_shared/ai-document-protocol.md)，识别本轮成熟度与实际范围。只补一份文档时更新该文件及直接相关引用，不自动生成全套PRD、决策一页纸或分享HTML；下文完整S8终稿冻结规则仅在交付完整正式PRD时适用，单文档不得冒称整站通过。

Agent／RAG／AIGC分别调用`qaqpm-agent-requirements`、`qaqpm-rag-requirements`、`qaqpm-aigc-requirements`；它们通常在S5产生首稿，S8补规则、接口、状态、异常和验收。没有首稿可按当前资料创建，不要求补做历史阶段。

## 2. 上游依赖
S5范围、AI能力清单与专题首稿；完整阶段读取S6/S7交接与S4差异化；可选S9早期或正式选型结论。立项决策一页纸可引用 `research/已确认决策表.md`；总控 Phase1 可能已有一页纸草稿。

## 3. 目标与通过线
- 同源**立项决策一页纸**先填满（可未冻），再分两套目录。  
- 课件八块映射齐全（含**角色权限、异常转人、AI 做什么／不做什么／怎么验收**）。  
- 测试能依据正式 PRD 写用例；开发与接口约定可执行。

### 立项决策一页纸硬门禁（P0）

展示名：**立项决策一页纸**（旧称「共享决策包」仅作内部别名）。  
文件：`立项决策一页纸.md`（模板 `templates/立项决策一页纸.md`；旧 `shared-decision-pack.md` 重定向说明）。

下列任缺 → **禁止**将正式 PRD 标为终稿完成；允许「PRD 草案」，且 `00` 索引必须红字「**立项决策一页纸未冻**」：
- 一句话目标、问题定义引用  
- MVP must / wont（含不做理由）  
- 差异化一句  
- S7 门禁引用（或明确「门禁草案路径」）  
- 非目标、里程碑、开放问题  
- 架构取舍摘要（执行位置／访问入口，引用 S5 表）  
- **已决｜仍要证明**对照（表格或两栏）  

空壳复制 PRD 目录表 ≠ 已冻。`frozen=false` 时一页纸顶部与索引**红字**，禁止标 S8 终稿。  
条件立项＋技术验证中项目用「未冻 + 验证日历」样例（见模板），不得假装已冻。

合订 MD 可交付，但 handoff 的 `prd_dir` / `agent_spec_dir` 必须与真实路径一致；合订时改用 `prd_path` / `agent_spec_path`，路径须真实存在或 `provisional: true`。

## 4. 引导流程
P0 **填满**立项决策一页纸（已决｜待证；尝试冻结）→ P1 选读者侧重 → P2 写正式 PRD（八块）→ P3 写开发与接口约定（Agent 模块 + 知识库若需要）→ P4 交叉检查范围与 S7 门禁 → P5 交接（frozen true/false 诚实填写；人话第一步）。

## 开发就绪交接

开发入口使用 [_shared/development-kit-protocol.md](_shared/development-kit-protocol.md)。交出可读取的 PRD、接口约定、功能验收项及 S7 标准引用；有稳定需求编号则沿用，没有时按当前范围建立引用，不强制重编号整份文档。

补清本轮 must/wont、输入输出、状态/异常/权限、数据归属、主要终端（默认 Web，WAP 为移动适配）、性能/成本约束、交付目标及阻塞项。埋点要回答的产品问题、事件和指标口径提前定义；实现与采集验证交 S10/S12。

S10 只补实施缺口，不复制第二套 PRD；开发仓库的 PRD 检查引用本文件事实。未冻结内容如实保留，条件验证不等于正式 PRD 完成。本站不自动拉取开发仓库。

## 10. 交接区
人话「接手后第一步」＋ YAML：`shared_decision_pack_frozen`, `decision_one_pager_path`, `prd_dir` 或 `prd_path`, `agent_spec_dir` 或 `agent_spec_path`, `next_station`→S9

## 11. 回流
范围争议 → S5/S6；门禁不清 → S7；一页纸空壳 → 停在 P0。

专题文件按能力ID与原路径引用，交接可补`ai_document_index_path`、`capability_ids`、`document_maturity`和`eval_object_refs`。S9结论改变候选或约束时回写同一需求；未冻结项如实列明。
