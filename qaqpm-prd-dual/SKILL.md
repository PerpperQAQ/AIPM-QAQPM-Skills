# QAQPM-双轨PRD（S8）

笔记锚点：day13 PRD 八块与功能五件事；day16 三主线与美团案例；vibe-prd 10 模块；架构 §6。

## 1. 何时用 / 何时不用
**用**：立项后需要可协作图纸与可编码规范。  
**不用**：尚未有 S7 黄金集草案（可少量交错写结构，但验收章不得空写「效果要好」）。

## 2. 上游依赖
S5/S6/S7 交接；S4 差异化；可选 S9 选型结论。

## 3. 目标与通过线
- 同源决策包先冻结，再分两套目录。  
- 课件八块映射齐全（含**角色权限、异常转人、AI 三问**）。  
- 测试能依据正式 PRD 写用例；Agent 规范可执行。

## 4. 引导流程
P0 冻结共享决策包 → P1 选读者侧重 → P2 写正式 PRD（八块）→ P3 写 Agent 模块（+知识库若需要）→ P4 交叉检查范围与 S7 门禁 → P5 交接。
